# 项目长期记忆

## 项目概况
- 产品：短剧盒（ShortDramaBox）——桌面短剧播放器，代码仓库 E:/projects/hongguo-short-drama-desktop，将发布到 GitHub 与 Gitee（双平台）。
- 核心卖点：极速稳定、仅约 6MB、免安装（绿色单文件）、零广告、跨平台（Windows 10/11 64位、macOS Intel/Apple Silicon、Linux）。
- 功能范围：刷剧（1080P、弹幕、倍速、自动连播、小窗、隐私、摸鱼模式）、找剧/排行榜、本地历史/收藏/点赞/追更/预约、剧集 MP4 下载、任务托盘、设置记忆、深浅主题。

## 约定
- README 主文件为 `README.md`（UTF-8 无 BOM；历史上曾用 GBK 的 README.MD，勿回退）。
